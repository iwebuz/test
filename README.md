# iWeb.uz — сайт компании

Статический сайт (HTML + CSS + JavaScript) без сборки и зависимостей. Его можно разместить на любом хостинге: загрузите файлы в корень домена `iweb.uz`.

## Структура

```
index.html                 главная (меню, hero-слайдер, услуги, портфолио, контакты)
404.html                   страница «не найдено»
css/style.css              все стили
js/main.js                 все скрипты
img/                       favicon и картинка для соцсетей (og-image.png)
blog/index.html            список статей блога
blog/*.html                статьи
blog/_template.html        шаблон новой статьи (закрыт от индексации)
robots.txt, sitemap.xml    файлы для поисковиков
```

## Как добавить статью в блог

1. Скопируйте `blog/_template.html` и назовите файл латиницей через дефис, например `blog/kak-vybrat-hosting.html`.
2. Замените все `{{...}}` в копии: заголовок, описание, дату, ссылку (slug) и текст. Поставьте `<meta name="robots" content="index, follow">`.
3. Добавьте карточку статьи в **начало** списка `<div class="posts">` в `blog/index.html` (и при желании на главную, в раздел «Блог»).
4. Добавьте адрес статьи в `sitemap.xml` и в блок `blogPost` (JSON-LD) в `blog/index.html`.
5. Оглавление статьи строится автоматически из заголовков `<h2>`.

Советы для SEO: один `<h1>` на странице, `title` до 60 символов, `description` 140–160 символов, ссылки на другие статьи и страницы услуг, регулярные публикации.

## Что нужно заменить перед запуском

- Телефон `+998 (00) 000-00-00`, e-mail `info@iweb.uz`, Telegram `@iweb_uz`: в `index.html` (контакты и JSON-LD) и в `js/main.js` (адрес для формы).
- Цифры в блоке статистики и проекты в портфолио: сейчас там примеры.
- Форма заявки открывает почтовый клиент (`mailto:`). Чтобы заявки приходили напрямую, подключите Formspree, Getform или Telegram-бота (место отмечено комментарием в `js/main.js`).
- После публикации добавьте сайт в Google Search Console и Яндекс Вебмастер и отправьте `sitemap.xml`.

## Локальный просмотр

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
